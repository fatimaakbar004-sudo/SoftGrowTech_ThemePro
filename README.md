# 🚀 ThemePro – Premium Theme Switcher Website

ThemePro is a modern SaaS-inspired web application featuring a premium Dark/Light theme switcher with Local Storage persistence, responsive design, smooth animations, and a professional user interface. The project focuses on delivering an engaging user experience through modern frontend development techniques.

---

## 🌟 Features

* 🌗 Dark & Light Theme Switching
* 💾 Theme Preference Saved Using Local Storage
* 📱 Fully Responsive Design
* ✨ Smooth Scroll Reveal Animations
* 📊 Animated Statistics Counter
* 💬 Interactive FAQ Accordion
* 🎨 Glassmorphism UI Design
* 🖱️ Cursor Glow Effect
* 🌈 Floating Background Blobs
* 📩 Contact Section with Modern Form Design
* ⚡ Smooth Theme Transition Effects
* 🎯 Modern SaaS Landing Page Layout

---
